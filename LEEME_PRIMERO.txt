ALEDEVOS V1.51 - GUIA RAPIDA PARA WINDOWS
========================================

NO necesitas memorizar comandos PowerShell.
NO necesitas cambiar la ExecutionPolicy global de Windows.

EMPIEZA HACIENDO DOBLE CLIC EN:

    START_ALEDEVOS.bat

El menu ofrece:

1) VER ESTADO MASTER
   - Rapido.
   - No ejecuta pruebas reales.
   - No instala nada.
   - No congela V1.
   - Solo muestra cuantos checks tienen evidencia y cuantos siguen pendientes.

2) COMPROBAR RUNTIMES REALES
   - Prueba OpenCode, Codex, Claude Code y Antigravity.
   - Primero busca cada CLI; si no existe, la marca BLOCKED y pasa al siguiente sin instalar su target.
   - En Windows tambien busca rutas conocidas fuera de PATH (por ejemplo, Antigravity en %LOCALAPPDATA%\agy\bin).
   - OpenCode Desktop y Antigravity IDE no sustituyen sus CLIs de terminal; P2 necesita opencode y agy respectivamente.
   - Usa targets desechables bajo .aledevos\state solo para runtimes realmente invocables.
   - No instala AleDevOS dentro de tus proyectos reales.
   - Si una CLI no existe, no tiene login o no puede invocar su modelo, ese runtime queda BLOCKED.
   - P2 traduce cada BLOCKED a una ACCION NECESARIA (instalar/activar CLI, /login, cuota, o reparacion AleDevOS).
   - Al final muestra un SIGUIENTE PASO RECOMENDADO; no necesitas interpretar los estados tecnicos.

3) INSTALAR ALEDEVOS EN UN PROYECTO
   - Pide la carpeta del proyecto.
   - Pide el adapter: Codex, Claude Code, OpenCode, Antigravity o Gemini alias.
   - Mientras V1 no este FROZEN, se recomienda usar un SANDBOX.

4) CAMPANA FINAL
   - Se usa al final, cuando ya hemos preparado los perfiles/evidencias P3-P8.
   - Ejecuta el runner final.
   - Solo puede emitir ALEDEVOS_V1_FROZEN si los 33 checks estan PASS.

POR QUE LOS BAT FUNCIONAN SI WINDOWS BLOQUEA LOS .PS1
-----------------------------------------------------
Los launchers llaman a PowerShell asi:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ...

Ese Bypass se aplica SOLO al proceso que abre el BAT.
No cambia LocalMachine, CurrentUser ni la politica global de Windows.
Al cerrar el proceso, desaparece.

Si tu PC esta administrado mediante AppLocker/WDAC o una Group Policy corporativa que
prohibe expresamente scripts, Windows puede seguir bloqueandolos; en ese caso hay que
resolver esa politica con el administrador del equipo.

USAR ALEDEVOS CON CODEX
-----------------------
Menu -> 3 -> Adapter 1 (Codex)

Equivale a:
    scripts\05-install-into-project.ps1 -ProjectPath <proyecto> -Adapter codex

USAR ALEDEVOS CON CLAUDE CODE
-----------------------------
Menu -> 3 -> Adapter 2 (Claude Code)

Equivale a:
    scripts\05-install-into-project.ps1 -ProjectPath <proyecto> -Adapter claude-code

IMPORTANTE
----------
Adapter != modelo.
El adapter es la herramienta/runtime que ejecuta AleDevOS en ese proyecto.
Multi-Model puede enrutar Judges u otras tareas a modelos distintos cuando exista un
binding real y autorizado.

ORDEN RECOMENDADO AHORA
-----------------------
1. Doble clic START_ALEDEVOS.bat
2. Opcion 1: Estado Master
3. Opcion 2: Comprobar runtimes reales
4. Resolver juntos los BLOCKED reales
5. Preparar la campana target
6. Opcion 4: Campana Final
7. 33/33 PASS -> Freeze Certificate -> ALEDEVOS_V1_FROZEN
8. Instalar la version congelada en proyectos reales
