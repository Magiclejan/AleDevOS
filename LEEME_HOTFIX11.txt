AleDevOS V1.51 - Hotfix11 AutoCampaign

OBJETIVO
- Separar claramente PAQUETE AleDevOS y PROYECTO activo.
- Guardar el proyecto activo una sola vez.
- Dejar de pedir manualmente la ruta del JSON de campana final.
- Descubrir automaticamente perfiles reales P3-P8.
- Generar la campana canonica en:
  <proyecto>\.aledevos\state\release\master\campaigns\FINAL_MASTER_CAMPAIGN.json
- Inyectar automaticamente esa campana al gate final.
- NO fabricar perfiles/evidencia que no existan: si faltan, PREPARAR queda BLOCKED con diagnostico.

INSTALACION
1. Extrae el contenido de este ZIP en la RAIZ de tu carpeta del paquete AleDevOS (la carpeta donde ya estan scripts\ y el launcher actual).
2. Permite reemplazar START_ALEDEVOS.bat / EMPEZAR_AQUI.bat si Windows lo pregunta.
3. Ejecuta START_ALEDEVOS.bat o EMPEZAR_AQUI.bat.

PRIMER USO
- Si solo existe un proyecto AleDevOS hermano del paquete, se selecciona automaticamente.
- Si hay varios, el launcher pregunta una sola vez.
- La seleccion se guarda en .aledevos\state\launcher\active-project.json del paquete.

SEGURIDAD
- El Hotfix no modifica el motor 1.51 ni los validadores Node.
- El script 67-final-master-gate.ps1 solo se parchea, con backup .hotfix11.bak, cuando se ejecuta la campana final y unicamente para aceptar ALEDEVOS_FINAL_CAMPAIGN desde el launcher.
