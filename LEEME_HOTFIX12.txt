AleDevOS V1.51 - Hotfix12 Multi-Project AutoCampaign

CORRECCION PRINCIPAL
Hotfix11 trataba un unico "proyecto activo" como estado persistente. Eso no escala: AleDevOS puede estar instalado en muchos proyectos y en rutas distintas.

HOTFIX12 CAMBIA EL MODELO
- AleDevOS mantiene un REGISTRO de proyectos conocidos, no un proyecto activo global.
- El registro vive por usuario en: %LOCALAPPDATA%\AleDevOS\launcher\projects.json
- La seleccion de proyecto es DE SESION. Al cerrar el launcher desaparece.
- Si solo hay un proyecto valido conocido, se selecciona automaticamente para esa sesion.
- Si hay varios, AleDevOS pregunta cual usar la primera vez que una accion necesita proyecto; durante el resto de esa sesion no vuelve a preguntar.
- Si el launcher se inicia desde dentro de un proyecto AleDevOS, ese proyecto se detecta automaticamente para esa sesion.
- Instalar/actualizar un proyecto lo registra automaticamente y lo selecciona solo para la sesion actual.
- Se pueden agregar o quitar proyectos del registro sin borrar ningun archivo del proyecto.
- El antiguo active-project.json de Hotfix11 se migra solo como PROYECTO CONOCIDO y deja de actuar como seleccion permanente.

CAMPANA FINAL
- Es independiente por proyecto.
- Cada proyecto mantiene su campana en:
  <proyecto>\.aledevos\state\release\master\campaigns\FINAL_MASTER_CAMPAIGN.json
- AleDevOS detecta perfiles P3-P8 del proyecto seleccionado.
- Si faltan perfiles reales, PREPARAR queda BLOCKED; nunca fabrica evidencia.
- EJECUTAR usa automaticamente la campana del proyecto de la sesion y no pide rutas JSON manuales.

INSTALACION
1. Extrae este ZIP encima de la raiz del paquete AleDevOS desde el que ejecutas el launcher.
2. Permite reemplazar START_ALEDEVOS.bat, EMPEZAR_AQUI.bat y scripts\70-aledevos-app.ps1.
3. Ejecuta START_ALEDEVOS.bat.

MENU NUEVO
1. Estado del proyecto de esta sesion
2. Comprobar runtimes reales del equipo
3. Instalar / actualizar AleDevOS en un proyecto
4. Preparar campana FINAL automaticamente
5. Ejecutar campana FINAL
6. Elegir/cambiar proyecto de ESTA SESION
7. Gestionar proyectos conocidos
8. Estado interno del PAQUETE AleDevOS
9. Salir
