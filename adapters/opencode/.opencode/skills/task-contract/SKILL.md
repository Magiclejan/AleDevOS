# Task Contract

Produce:
- Objective: one outcome sentence.
- In scope: explicit behaviors/files/domains.
- Out of scope: likely adjacent work that is intentionally excluded.
- Acceptance criteria: observable, testable statements.
- Invariants: existing behavior that must remain true.
- Risk: LOW/MEDIUM/HIGH and why.
- Verification: exact evidence needed before completion.

If information is missing, choose the least destructive interpretation and label the assumption.
