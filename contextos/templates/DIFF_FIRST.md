# Diff-first review packet

Preferred review order:

1. task contract / acceptance criteria;
2. approved scope;
3. diff summary and bounded patch evidence;
4. deterministic verification evidence;
5. structured handoff / decision records;
6. targeted excerpts only when needed;
7. full files only as an explicit fallback with a reason.

A reviewer should not re-read entire modified files when the diff plus focused evidence is sufficient.
